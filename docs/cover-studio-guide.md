# 翻唱工作室使用说明

## 开始前

工作室运行在 Cove 的 Windows Tauri 桌面窗口中。请使用桌面应用启动，不要直接用普通浏览器打开 Vite 地址，因为浏览器没有 Tauri 的本地文件、工程和 stem 处理接口。

`.ncm` 转换还需要发布包内的 `resources/ncm2acc` 运行资源，包括固定版本的 `ncm2acc` 脚本、`ncmdump-go.exe`、FFmpeg、Python/audio-separator 和 BS-Roformer 模型。没有这些资源时，仍可导入 WAV、MP3 等本地伴奏，但 `.ncm` 任务会提示缺少 runner。

## 一次完整录音流程

1. 在播放器中播放或选中一首网易云歌曲，点击歌曲信息旁的麦克风按钮，或从歌曲操作菜单选择“打开翻唱工作室”。工作室会沿用原曲封面、歌名、歌手和歌词时间戳。
2. 在左侧“伴奏输入”中点击“自动下载当前歌曲并生成伴奏”。应用会根据当前网易云歌曲 ID 获取可播放音频，下载到应用临时目录，再用 audio-separator 分离人声，完成后自动导入伴奏轨。此过程不会移动或修改原始在线播放源。
   同一首歌的伴奏会缓存在本机，之后再次进入工作室会直接复用，不会重复分离；需要更新结果时点击“重新生成伴奏”。
3. 如果自动下载不可用，可以选择“选择 .ncm 生成伴奏”。`.ncm` 文件会复制到临时任务目录，原始文件不会被移动或删除；任务会依次显示准备文件、解密、加载模型、分离人声和写入伴奏的进度。
4. 如果没有 `.ncm`，也可以使用“导入音频”直接导入 WAV、MP3 或 FLAC。伴奏从 0 秒开始，作为歌词和录音的主时钟。
5. 点击“人声轨”添加一条人声轨。再次添加可以录制和声、叠唱或不同版本。每次在同一条轨道录音都会生成一个新的 take，旧 take 会保留在工程中。
   如果需要对照原唱，点击轨道区的“原曲”会尝试下载当前歌曲并加入“原曲参考”音轨；也可以点击“本地”选择已有的原曲文件。该音轨默认静音，取消静音或独奏后才会播放。
6. 在右下方选择麦克风。软件监听默认关闭，建议戴耳机后再打开“耳机监听”，避免扬声器啸叫。首次按录音按钮时，Windows 才会请求麦克风权限。
7. 先播放伴奏找到进入点，再选中人声轨点击录音。停止后录音会按“输入延迟”毫秒值放回时间线。延迟过早就增大数值，延迟过晚就减小数值；也可以直接拖动时间线中的 clip 做细调。
8. 选中轨道后可以调整三段 EQ、压缩比例、混响和延迟。M 是静音，S 是独奏，音量滑块控制增益。效果参数以非破坏方式保存，播放和离线导出使用同一套参数。
9. 使用底部播放、暂停、回到开头和进度条检查歌词同步。当前歌词会跟随共享播放头高亮。
10. 新工程在点击“保存”前只保留在当前工作室会话中，不会出现在“打开工程”列表，也不会写入本地工程目录。点击标题旁的铅笔按钮可以自定义工程名称，按 Enter 或移开输入框确认；点击“保存”后才会写入 `%APPDATA%/Netease Music Player/StudioProjects/<project-id>`，下次可以从“打开工程”菜单重新打开。已经保存过的工程会继续自动保存编辑内容。旧版本留下的工程可以在“工程”菜单中逐项点击垃圾桶删除。
11. 打开右上角“导出”菜单，选择“在播放器中播放翻唱”。应用会离线渲染当前伴奏、人声和效果，然后切回普通播放器播放，并继续显示工程中的原封面、歌名、歌手和同步歌词。
12. “导出工程包”生成 `.cove-studio` 文件；“导出 WAV”生成 24-bit WAV；“导出 MP3”通过本地 FFmpeg 生成 320 kbps MP3。导出过程是离线渲染，不依赖当前播放状态。

## 常见问题

- **点击 `.ncm` 后提示缺少 runner**：检查发布目录是否存在 `resources/ncm2acc/ncm2acc-runner.exe` 或 `resources/ncm2acc/runner.py`，并确认其旁边已经放入上游脚本、`ncmdump-go.exe`、FFmpeg、Python/audio-separator 和模型。
- **伴奏任务失败**：查看任务提示中的阶段和错误码，先确认 `.ncm` 文件本身可以被 `ncmdump-go` 解密，再检查 FFmpeg、模型和显存/内存。没有 NVIDIA/CUDA 时应使用 CPU 回退运行包。
- **录音没有声音**：检查 Windows 麦克风权限、工作室里的设备菜单和输入增益。软件监听关闭不会影响录音文件，只影响耳机回放。
- **人声听起来整体提前或滞后**：使用“输入延迟”校正。不同声卡、蓝牙耳机和 USB 麦克风应分别记录校正值。
- **QQ 音乐或酷狗歌曲没有 `.ncm`**：使用“导入音频”导入你拥有的本地伴奏文件。

第一版不包含自动修音、自动节拍拉伸、自动人声识别对齐和插件系统；录音、工程和导出文件默认只保存在本机。
